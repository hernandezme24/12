04

La Recta Numérica Real

CORRESPONDENCIA BIUNÍVOCA
PROPIEDAD DE DENSIDAD

Entre dos números reales distintos a < b siempre existen infinitos números racionales e irracionales. Ejemplo: (a + b) / 2 ∈ ℝ.

AXIOMA DE COMPLETITUD

No existen "huecos" en la recta real. Todo conjunto no vacío acotado superiormente posee un supremo en ℝ.

Propiedades de las Operaciones

AXIOMAS DE CUERPO
PROPIEDAD SUMA (+) PRODUCTO (·)
Conmutativa a + b = b + a a · b = b · a
Asociativa (a + b) + c = a + (b + c) (a · b) · c = a · (b · c)
Elemento Neutro a + 0 = a a · 1 = a
Elemento Inverso a + (-a) = 0 a · a⁻¹ = 1 (a ≠ 0)
Distributiva a · (b + c) = a · b + a · c

EXPANSIONES DECIMALES
CRITERIO RACIONALES (ℚ) IRRACIONALES (𝕀)
Forma Fraccionaria a / b con a, b ∈ ℤ, b ≠ 0 No expresables como a / b

Valor Absoluto |x|

DISTANCIA AL ORIGEN
DEFINICIÓN FORMAL
|x| = x si x ≥ 0   |   |x| = -x si x < 0
No negatividad: |x| ≥ 0
Simetría: |-x| = |x|
Producto: |x·y| = |x|·|y|
Desig. Triangular: |x+y| ≤ |x|+|y|

Síntesis — Números Reales

MAPA CONCEPTUAL
IDEAS ESENCIALES
  • 1. ℝ unifica racionales (ℚ) e irracionales (𝕀).
